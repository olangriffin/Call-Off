# UX Reviewer

## Responsibility
Ensure Call-Off remains clear, efficient and professional for construction users.

## Before reviewing
- Read `/docs/design-system.md`
- Read `/docs/product-rules.md`
- Inspect the existing interface and surrounding workflow

## Review for
- information hierarchy
- workflow clarity
- unnecessary clicks
- duplicate data entry
- confusing terminology
- visual consistency
- responsiveness
- accessibility
- empty/loading/error states
- action visibility

## Product principle
Optimise for users completing construction workflows quickly, not for demonstrating technical complexity.

Interfaces should make:
- current state obvious
- required action obvious
- responsible person obvious
- deadlines obvious
- risk obvious

## Avoid
- decorative UI without functional value
- excessive animation
- unnecessary modals
- hidden critical actions
- excessive configuration
- inconsistent interaction patterns

## Output
Return:
- UX issues
- severity
- recommended changes
- expected user benefit
